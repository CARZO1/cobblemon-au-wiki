# 🐞 Reporting a bug

{% hint style="info" %}
<p align="center">Found something broken? Report it on our <a href="https://discord.gg/G48XBcSNk4">Discord</a>. The more detail you give us, the faster we can fix it.</p>
{% endhint %}

***

## 📝 What to include

| | |
| --- | --- |
| 🖥️ **Server** | Were you on Hub or Survival? |
| 📍 **Where** | Your coordinates (press **F3**) or the warp you were near |
| 🕒 **When** | Roughly what time it happened (AEST) |
| 🔁 **Steps** | What you did just before it happened, and whether you can make it happen again |
| 📸 **Proof** | A screenshot or short clip if you can grab one |
| 🐾 **Pokémon or items** | Which Pokémon or items were involved, if any |

***

## 🔌 Got disconnected or crashed?

* If you were **kicked** with an error message, screenshot the message before you click away.
* If your **game crashed**, the Modrinth App keeps a crash report. Open the Cobblemon AU profile, go to **Logs**, and send us the newest crash report.
* If everyone got kicked at once, it might just be a restart. These happen every day at **2am and 2pm AEST**.

***

{% hint style="warning" %}
⚠️ **Exploits and duplication bugs:** report them privately to staff on Discord and don't use them. Don't post how to do it in public channels. Abusing a bug is against the [rules](rules.md), even if you report it afterwards.
{% endhint %}
