# 🔌 Joining the server

{% hint style="info" %}
<p align="center">Cobblemon AU needs its own modpack. It's free on Modrinth and comes with the server already in your multiplayer list.</p>
{% endhint %}

***

## 📦 Install the modpack

{% stepper %}
{% step %}
### Get the Modrinth App

Download and install the [Modrinth App](https://modrinth.com/app). It handles the modpack, Java and updates for you.
{% endstep %}

{% step %}
### Install Cobblemon AU

Open the [Cobblemon AU modpack page](https://modrinth.com/modpack/cobblemon-au) and click **Install**. The pack runs on Minecraft 1.21.1 with Fabric, and the app sets all of that up.
{% endstep %}

{% step %}
### Launch and join

Press **Play**. Go to **Multiplayer** and you'll see **Cobblemon AU** already in your server list. If it's missing, click **Add Server** and enter:

`cobblemon-au.com`
{% endstep %}

{% step %}
### Accept the server resource pack

When you join you'll be asked to download the server resource pack. Click **Yes**. It's required, and it adds our custom Pokémon skins, Radiant textures and rank badges.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
✅ That's it. You'll land in the Hub lobby. Head to [Your first steps](first-steps.md) next.
{% endhint %}

***

## 🔄 Updating the modpack

When we release an update, your game has to match the server or you won't be able to join. Close the game completely first, then:

1. Open the Modrinth App.
2. Click into the **Cobblemon AU** page.
3. Go to the **Content** tab.
4. Click **Switch version** (next to the ⇄ arrows icon).
5. Select the version marked **Current**.
6. Click **Update** in the bottom-right corner.
7. Wait for it to finish, then launch the game as normal.

***

## 🛠️ Can't connect?

| Problem | Try this |
| --- | --- |
| "Mod mismatch" or "Incompatible" error | Your modpack is out of date. Update it using the steps above. |
| Stuck downloading the resource pack | Leave and rejoin. If it keeps happening, restart the game. |
| Server shows as offline | We restart every day at **2am and 2pm AEST**. Give it a minute and try again. |
| Something else | Ask in our [Discord](https://discord.gg/G48XBcSNk4). |
