# Voting

{% hint style="info" %}
<p align="center">Voting helps new players find Cobblemon AU, and every vote gets you a free <strong>Vote Key</strong>.</p>
{% endhint %}

***

## ✅ How to vote

{% stepper %}
{% step %}
### Open the vote list

Type `/vote` in game to see all five voting sites as clickable links.
{% endstep %}

{% step %}
### Vote on each site

Open each link, enter your Minecraft username and submit your vote. Each site lets you vote once a day.
{% endstep %}

{% step %}
### Collect your keys

You'll get one **Vote Key** for every vote. Open them at the crates on the Hub with `/crates`.
{% endstep %}
{% endstepper %}

## 🏅 Vote milestones

Your votes add up over time. Hit these totals for a bonus on top of your Vote Keys. Type `/votemilestones` to check them in game.

| Total votes | Reward |
| --- | --- |
| 10 | Hat Crate key |
| 50 | Plushie Crate key + $10,000 |
| 100 | Mega Stone Crate key + $25,000 |
| 250 | Shiny Crate key + $50,000 |
| 750 | Legendary Crate key |

{% hint style="success" %}
💡 Voting on all five sites every day gets you 35 Vote Keys a week, and gets you to your first milestone in two days.
{% endhint %}
