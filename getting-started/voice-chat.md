# Voice Chat

{% hint style="info" %}
<p align="center">Voice chat is built into the modpack, so there's nothing extra to install. Talk to players standing near you, or make a group to chat with your friends wherever they are.</p>
{% endhint %}

***

## 🎙️ Setting it up

{% stepper %}
{% step %}
### Open voice chat

Press **V**. The first time you open it, it helps you pick your microphone and choose how you want to talk.
{% endstep %}

{% step %}
### Choose how you talk

* **Voice activation:** your mic switches on by itself whenever you speak.
* **Push to talk:** your mic only works while you hold a key. Our modpack doesn't set a push to talk key, so pick one in **Options → Controls → Key Binds**, under **Voice Chat**.
{% endstep %}

{% step %}
### Test it

Open the voice chat menu with **V** to check your microphone and adjust volumes. When you talk, a small microphone icon shows in the corner of your screen.
{% endstep %}
{% endstepper %}

***

## ⌨️ Keys

| Key | What it does |
| --- | --- |
| **V** | Open the voice chat menu |
| **G** | Open groups |
| **.** (full stop) | Mute or unmute your microphone |
| **,** (comma) | Turn voice chat off or on completely |
| **H** | Hide or show the voice chat icons |
| Not set | Push to talk and whisper. Set them in **Options → Controls → Key Binds**. |

***

## 🔊 Who can hear you

* **Nearby players:** anyone within **48 blocks** can hear you, and you get quieter the further away they are.
* **Whisper:** set a whisper key and only players within **24 blocks** will hear you.
* **Groups:** press **G** to make or join a group. Everyone in the group can hear each other no matter how far apart they are on the same server. You can add a password to keep it private.

Voice chat works on both the Hub and Survival, and reconnects by itself when you switch servers.

***

## 🛠️ Not working?

| Problem | Try this |
| --- | --- |
| Nobody can hear me | Press **V** and check the right microphone is selected. Make sure you haven't muted yourself with **.** |
| I can't hear anyone | Check the **Voice** volume in **Options → Music & Sounds**, and that voice chat isn't turned off with **,** |
| Push to talk does nothing | Set a push to talk key in **Options → Controls → Key Binds** |

{% hint style="warning" %}
⚠️ The [server rules](rules.md) apply in voice chat too. Be kind, and keep it friendly for everyone.
{% endhint %}
