# 🎁 Kits

{% hint style="info" %}
<p align="center">Kits are claimed on the <strong>Hub</strong>. Type <code>/kits</code> to open the kit menu. If you use it on Survival, you'll be sent to the Hub.</p>
{% endhint %}

***

## 🎒 Starter kit

Everyone gets the **Starter** kit. You can claim it again every 30 days.

| Item | Amount |
| --- | --- |
| Stone Axe, Pickaxe and Shovel | 1 each |
| Golden Hoe (your land claim tool) | 1 |
| Torches | 32 |
| Poké Balls | 20 |

***

## 🏅 Rank kits

Every rank has its own kits that refresh on a timer, plus a one-time bonus when you get the rank.

| Kit | How to claim |
| --- | --- |
| Regular rank kits | Open `/kits` and click the kit |
| One-time rank bonus | Type `/rankbonus` on the Hub |
| Monthly Supporter kit | Open `/kits` |

See [Ranks / Supporter](../getting-started/supporting.md) for more about ranks.

{% hint style="warning" %}
⚠️ Make sure you have space in your inventory before claiming a kit.
{% endhint %}
